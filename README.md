# Оценка калибровки нейросетевых классификаторов на основе MC Dropout в условиях сдвига распределения данных

Данный репозиторий содержит код и результаты экспериментов по оценке надежности нейронных сетей в задачах классификации изображений. Исследуется поведение метода Monte Carlo Dropout (MC Dropout) при искажении входных данных (сдвиге распределения).

## Описание проблемы

Стандартная метрика точности (Accuracy) не отражает степень уверенности модели в своих предсказаниях. В критически важных системах (автономное вождение, медицинская диагностика) модель должна корректно определять ситуации, когда она не уверена в ответе из-за незнакомых или зашумленных данных. 

Цель работы — проверить, насколько адекватно метод MC Dropout сигнализирует о ненадежности предсказаний при добавлении аддитивного гауссовского шума к входным изображениям.

## Методология

1. **Модель:** Сверточная нейронная сеть ResNet-18, модифицированная добавлением слоя Dropout (p=0.5) перед финальным полносвязным слоем.
2. **Данные:** Датасет CIFAR-10 (10 классов, 60 000 изображений размером 32x32 пикселя).
3. **Оценка неопределенности:** Выполняется T=30 стохастических прогонов (Dropout остается активным на этапе тестирования). В качестве метрики неопределенности используется дисперсия вероятностей классов.
4. **Метрика калибровки:** Expected Calibration Error (ECE) — показывает разницу между заявленной уверенностью модели и ее реальной точностью (разбиение на 10 корзин).
5. **Сценарии тестирования:** Чистые данные, умеренный шум (σ=0.5), сильный шум (σ=1.0).

## Результаты эксперимента

В таблице представлены результаты для трех сценариев:

| Условия | Accuracy | Средняя дисперсия | ECE |
| :--- | :--- | :--- | :--- |
| Чистые данные | 74.46% | 0.0078 | 0.0366 |
| Умеренный шум (σ=0.5) | 53.71% | 0.0129 | 0.1900 |
| Сильный шум (σ=1.0) | 34.88% | 0.0161 | 0.3584 |

### Основные выводы

*   При увеличении уровня шума точность модели падает, а средняя дисперсия предсказаний растет. Модель начинает "чувствовать" искажение данных.
*   Однако метрика ECE возрастает катастрофически: с 0.0366 на чистых данных до 0.3584 при сильном шуме (рост в 10 раз).
*   Это означает, что в условиях сдвига распределения модель не только ошибается, но и теряет адекватность оценки собственной уверенности, оставаясь неоправданно самоуверенной.
*   **Практический вывод:** Использование "сырого" MC Dropout без дополнительных методов пост-хок калибровки (например, Temperature Scaling) не гарантирует надежности в задачах, критичных к ошибкам.

## Структура репозитория

*   `Dropout.py` — основной скрипт для обучения модели, проведения тестов с шумом и вычисления метрик (Accuracy, Дисперсия, ECE).
*   `uncertainty_histograms.png` — гистограммы распределения неопределенности для чистых и зашумленных данных.
